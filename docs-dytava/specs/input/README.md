# Dytava — Input Specification

**Document ID:** INP-000  
**Version:** 0.1.0  
**Status:** DRAFT  
**Platform:** Flutter — Android P0, iOS P1

## 1. Mục đích

Tài liệu này là điểm truy cập chính cho các đặc tả về dữ liệu đầu vào của hệ thống Dytava (ExcelCompare).

## 2. Phạm vi

Nhóm tài liệu Input mô tả:

- Nguồn dữ liệu A và B.
    
- Các định dạng tệp đầu vào.
    
- Cấu trúc dữ liệu bảng.
    
- Kiểu dữ liệu và thông tin nguồn gốc.
    
- Cấu hình nhập dữ liệu.
    
- Các quy tắc kiểm tra đầu vào.
    

## 3. Nguyên tắc

- Không chỉnh sửa dữ liệu nguồn.
    
- Không tự động chuyển đổi kiểu dữ liệu gây mất thông tin.
    
- Phân biệt dữ liệu gốc và dữ liệu đã chuẩn hóa.
    
- Những trường hợp đầu vào không rõ ràng phải được ghi nhận để xử lý hoặc xác nhận.
    

## 4. Trạng thái

Đang biên soạn. Chưa phải đặc tả đã phê duyệt.
